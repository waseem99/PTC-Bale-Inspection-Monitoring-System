# Dashboard Web

Planned React, TypeScript and Vite operational portal for the PTC Bale Inspection PoC.

## Responsibilities

- fixed-user PoC login and protected routes;
- operations overview and large KPI cards;
- four-camera monitoring layout;
- event/violation list and filters;
- event detail, evidence, review status and remarks;
- system health and basic reports;
- mock-data mode for demos and live-API mode for integration;
- local deployment first, with optional approved Azure hosting.

## Exclusions

- no AI inference or SOP logic;
- no direct RTSP credentials in the browser;
- no database access from the frontend;
- no complete user-management module for the PoC;
- no Power Apps or Power BI dependency for core operation.

Feature development begins under issues #44–#48 after the dashboard flow is approved.
