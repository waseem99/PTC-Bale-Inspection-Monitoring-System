# Azure Infrastructure

Planned Bicep and deployment assets for client-approved Azure components only.

## Possible approved responsibilities

- separately hosted development portal;
- remote/central React and Node.js hosting;
- Microsoft Entra ID integration;
- synchronized Azure Database for PostgreSQL metadata;
- protected PostgreSQL connection configuration and migration job;
- private Blob evidence storage;
- Key Vault, monitoring and deployment identity;
- optional Azure Web PubSub.

Azure must not become a dependency for local camera processing, AI inference, PostgreSQL persistence, evidence generation, event review or the local dashboard.
