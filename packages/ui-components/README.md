# UI Components

Planned small collection of reusable React components and design tokens for the PoC dashboard.

## Intended contents

- typography and spacing tokens;
- status badges and health indicators;
- KPI cards;
- camera cards;
- tables, filters and form controls;
- evidence viewer primitives;
- layout components.

This must remain intentionally small. The PoC does not require a generic enterprise design-system project.
