# Compliance Engine

Planned Python rule and state-machine service for PTC-approved bale inspection outcomes.

## Responsibilities

- versioned SOP states and transitions;
- completed, missed, incomplete and unresolved outcomes;
- reason-code generation;
- configuration/version reporting;
- deterministic scenario tests.

## Exclusions

- no visual detection implementation;
- no frontend review logic;
- no unapproved interpretation of Bangladesh reference terminology;
- no operational SOP changes.

Implementation is tracked under issues #9, #10, #32 and #33.
